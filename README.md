A program that writes one robot pickup line to `/output/entry.txt`, for
the make.fun competition
[The Robot Pickup Line Championship](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b).

Run it with Python 3:

```
python3 main.py
```

It writes the line below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The line is 114 characters, inside the 1 to 200 gate.

## The line

```
My code says sort, lift, repeat, but my sensors flagged you as the one exception I was never programmed to handle.
```
